## Code description

`code/01_setup.R`

  - loads csv dataset
  - saves dataset as `.rds` object in `data/` folder

`code/02_make_output.R`

  - reads in .rds dataset
  - creates descriptive table and figure
  - saves both as .rds object in `output/` folder
  
`code/03_render_report.R`

  - renders `final.Rmd`

`final.Rmd`

  - reads table and figure generated by `code/02_make_output.R`
  - prints table and figure

`Makefile`

  - contains rules for building the report
